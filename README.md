 🎓 EduVerse

### Your Learning Adventure

EduVerse is an interactive web-based learning platform that transforms learning into a 2D adventure experience.

Students can explore learning worlds, complete quests and quizzes, receive personalized assistance from an AI learning companion, earn XP and badges, track their learning progress, and connect with friends through profiles and leaderboards.

---

## 🌟 Concept

Learning should not feel like simply reading materials and answering questions.

EduVerse combines:

- 🧠 Learning
- 🎮 Gamification
- 🤖 AI-assisted learning
- 👥 Social interaction
- 🎨 2D adventure experience

into one learning journey.

### Core Learning Loop

```text

```

## 🎯 Target Users

EduVerse is initially designed for:

SD students in grades 4–6
SMP students in grades 7–9

The MVP focuses on creating an engaging learning experience through a modern 2D adventure interface.

## 🤖 Kibo — AI Learning Companion

Kibo is EduVerse's AI learning companion.

Instead of acting as a standalone chatbot, Kibo is integrated directly into the learning experience.

Kibo can help students with:

- 📖 Explanations
- 💡 Hints
- 🧩 Examples
- ❌ Mistake feedback
- 🎯 Learning guidance

The goal is to help students understand concepts rather than simply provide answers.

## 🎮 Gamification
**⭐ XP**

Students earn XP through learning activities.

Examples:

Complete learning material → +20 XP
Complete quiz → +50 XP
Complete quest → +100 XP
Complete challenge → +50 XP

**🏅 Badges**

Students can unlock achievements such as:

- 🧠 Math Explorer
- 🔥 7 Day Learner
- 💯 Perfect Challenge
- 🗺️ World Explorer
- 🤖 Curious Mind
- 🔥 Streak

Students are encouraged to maintain consistent learning habits through learning streaks.

**📊 Progress**

Learning progress is tracked separately from XP to represent the student's learning journey.

**🧙 Character System**

Each student has a 2D character that becomes their visual identity throughout EduVerse.

Characters can appear on:
- Dashboard
- Adventure map
- Quest
- Profile
- Friends
- Leaderboard

## 👥 Social Features

EduVerse includes lightweight social features designed around learning achievements.

Students can:

- 👤 View other student profiles
- ➕ Add friends
- 🔔 Accept friend requests
- 🏆 Compare XP through the friends leaderboard
- 🏅 Showcase achievements

The MVP does not include public chat or direct messaging.

## 🚀 Getting Started
1. Clone the repository
```bash
git clone https://github.com/davidkhasbiya/eduverse.git
cd eduverse
```
2. Install frontend dependencies
```bash
cd frontend
npm install
```
3. Start the development server
```bash
npm run dev
```
Open:
```bash
http://localhost:3000
```
